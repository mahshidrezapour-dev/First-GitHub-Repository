# Personal Information Manager

A Python program that collects personal information, stores it in a dictionary, and demonstrates two approaches to organizing data using a function and a class.

## Features

- Collect a person's name, age, job, and city
- Store personal information in a dictionary
- Check eligibility based on age
- Collect and organize information using a function
- Implement the same process using a class

## Concepts Practiced

- Functions and return values
- Dictionaries
- Classes and objects
- The `__init__` method
- Instance attributes
- Conditional statements
- User input and type conversion

## How to Run

Run `first.py` using Python and enter the requested information in the terminal.
